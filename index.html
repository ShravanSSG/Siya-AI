A more personal way to talk to AI.

Meet SIYA AI, a personal AI assistant project built to make AI interaction feel more natural, personal and engaging. Combining conversational AI, voice interaction, memory and a distinctive desktop companion experience, SIYA is developed with a focus on usability, personality and thoughtful design.

SIYA AI explores what happens when an assistant has a recognizable identity instead of a blank text box. The project grows through experimentation and refinement, and aspirations on this page are labelled as aspirations.

SIYA is actively evolving. Some capabilities are ready to use, some are experimental and others are still on the roadmap. SIYA has not been officially released yet, and using her requires your own Gemini API key.

How a conversation with SIYA flows.

From launch to reply, the experience is designed to feel like talking to someone, not operating a tool.

  1. Start SIYAOpen the app and SIYA is ready on your desktop.
  2. Speak or typeInteract through the supported input method.
  3. She thinksYour request goes through the configured AI integration.
  4. She answersSIYA replies through the interface and, with voice enabled, out loud.
  5. She remembersWhere memory is used, saved context helps personalize later conversations.

Bring your own character.

SIYA does not include a character model inside the app. If you want a character on screen, you can add your own .pmx or .zip model.

model.pmxmodel.zipVISUAL DEMO ONLY
  1. Get a modelUse one you made, or one whose licence lets you use it this way.
  2. Pick a formatA single .pmx file, or a .zip that bundles the model with its textures.
  3. Add it to SIYALoad the file from the app. SIYA does not provide one for you.

LICENCE  Models come with their own terms. Check what the creator allows before you use or share one.

Under the hood.

This page and the SIYA application use different technology. Here is each, kept simple.

This website

  • Single-page HTML, CSS and vanilla JavaScript
  • Scroll-linked animation and a light canvas particle layer
  • Respects reduced-motion settings

SIYA application

  • Gemini Live API for live voice conversation
  • Local Node.js backend with WebSocket communication
  • Tauri for the desktop shell
  • Your own Gemini API key, added in settings
  • Memory stored in local browser storage
You→SIYA interface→Assistant and backend→Gemini Live→Voice and text reply

Simplified view. Not every component is active in every build. API keys live in your own configuration and never on this site.

Where SIYA is, and where she is heading.

A direction, not a promise: no release dates or commitments are made here.

Current foundation

  • Conversational assistant
  • Voice conversation through Gemini Live
  • Local memory with a dashboard
  • Name and API key setup
  • Break reminders after 30 minutes of screen activity
  • Voice-controlled shutdown and sleep
  • Character-led interface

In development

  • Wake-word reliability
  • Desktop companion behaviors

Future vision

  • SIYA Cross Device Control (SCDC)
  • A richer 3D companion
  • Deeper screen understanding
  • Expanded desktop integrations
  • Better voice reliability
  • More personalization
